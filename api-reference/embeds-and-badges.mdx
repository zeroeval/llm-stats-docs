Embeds let you show LLM Stats data on a public page with a URL that is safe to put in HTML. They are the recommended way to satisfy [attribution](/api-reference/attribution) and the only way to show live data in a browser without proxying the API through your backend.

Embeds are served from `https://api.llm-stats.com/stats/embed/…` and require **no** `Authorization` header. They are not counted against your daily quota and do not count toward your burst limit.

## Surfaces

| URL | Returns | Use in |
| --- | --- | --- |
| `/stats/embed/{token}.svg` | A badge image | `<img>` |
| `/stats/embed/{token}` | An HTML widget (table, chart, or model card) | `<iframe>` |
| `/stats/embed/{token}/go` | `302` redirect to the source page on llm-stats.com with your `utm_source` | `<a href>` |

### Badge

```html
<a href="https://api.llm-stats.com/stats/embed/eyJ2IjoxLCJpIjoiaW50XzlmM2IiLCJrIjoiYmFkZ2UiLCJtIjoiZ3B0LTUtMjAyNS0wOC0wNyJ9.5b9c1f4e2a7d3c8b/go" rel="noopener">
  <img
    src="https://api.llm-stats.com/stats/embed/eyJ2IjoxLCJpIjoiaW50XzlmM2IiLCJrIjoiYmFkZ2UiLCJtIjoiZ3B0LTUtMjAyNS0wOC0wNyJ9.5b9c1f4e2a7d3c8b.svg"
    alt="GPT-5 — #1 in coding on LLM Stats"
    height="20"
  />
</a>
```

Badges are SVG, render at any size, and refresh their content on our side; you never need to change the URL. Cache headers allow browsers to hold a badge for up to one hour.

Badge kinds: `rank` (position in a category), `score` (one benchmark), `price` (input/output per million), and `source` (a plain "Data from LLM Stats" mark).

### Iframe embed

```html
<iframe
  src="https://api.llm-stats.com/stats/embed/eyJ2IjoxLCJpIjoiaW50XzlmM2IiLCJrIjoicmFua2luZ3MiLCJjIjoiY29kaW5nIiwibiI6MTB9.9e4d8b1c7a2f6e3d"
  width="100%"
  height="420"
  loading="lazy"
  title="Top 10 coding models — LLM Stats"
  sandbox="allow-scripts allow-popups allow-top-navigation-by-user-activation"
></iframe>
```

Widgets carry their own attribution footer, follow `prefers-color-scheme`, and support `?theme=light|dark` to force one. Widget kinds: `rankings` (top-N table for a category), `model` (a card for one model), `compare` (up to 5 models side by side), and `chart` (a history line, subject to your plan's [history window](/api-reference/historical-data)).

### Redirect link

```html
<a href="https://api.llm-stats.com/stats/embed/TOKEN/go" rel="noopener">See full rankings on LLM Stats</a>
```

`/go` redirects to the matching page on llm-stats.com and appends `utm_source=<your integration>` so referral traffic is credited to your [integration](/api-reference/attribution#verified-integrations).

## Token structure

A token is created for you in the developer console when you add an integration and choose what to embed. You do not build tokens yourself, but the format is documented so you know what is in them.

```text
<base64url(JSON payload)>.<hex HMAC-SHA256 signature>
```

```json
{
  "v": 1,
  "i": "int_9f3b",
  "k": "rankings",
  "c": "coding",
  "n": 10
}
```

| Field | Meaning |
| --- | --- |
| `v` | Token format version. |
| `i` | Integration id. Ties the embed to an organization and its allowed host. |
| `k` | Kind: `badge`, `rankings`, `model`, `compare`, `chart`, `source`. |
| `m`, `c`, `b`, `n`, … | Kind-specific selectors (model id, category, benchmark, count). |

The signature is `HMAC-SHA256` over the base64url payload with a key we hold. The payload is readable by anyone — **do not put anything private in an embed configuration** — but it cannot be altered without invalidating the signature.

<Warning>
  A token is a **public rendering identifier**, not a credential. It grants no
  access to `/stats/v1/*`, cannot be exchanged for an API key, and carries no
  quota. Putting a token in HTML is safe; putting an API key in HTML is not.
</Warning>

## Allowed host

Each integration declares an allowed host (for example `example.com`, which also covers subdomains). Embed requests are validated against it:

- `<img>` and `<iframe>` requests must carry a `Referer` (or `Sec-Fetch-Site`/`Origin`) matching the allowed host. Requests from other hosts receive a `source` badge or a placeholder widget that still links to LLM Stats, so a copied token cannot be used to brand someone else's page.
- Requests without a referer (privacy extensions, some RSS readers, direct navigation) are served normally, but do not count as traffic evidence for verification.
- `/go` redirects work from anywhere.

Change the allowed host in the developer console; existing tokens keep working because the host lives on the integration, not in the token.

## Limitations

- Tokens do not expire, but you can **revoke** them from the console. A revoked token renders a `source` badge or placeholder and stops counting for verification.
- Embeds show the same data as the public website. They cannot display Builder- or Commercial-only data (for example history beyond 6 months in a `chart`) on a page whose integration belongs to a Community organization.
- Widgets are read-only and do not accept viewer input beyond theme; use the API for interactive experiences.
- Embeds serve live data; they are not a way to redistribute the dataset. Scraping widget HTML to extract data is a terms violation.
- Badge and widget loads are logged as described in [Privacy and analytics disclosure](/api-reference/attribution#privacy-and-analytics-disclosure).
