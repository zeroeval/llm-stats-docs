The LLM Stats API gives you direct, read-only access to the same dataset that powers [llm-stats.com](https://llm-stats.com) — every model, every benchmark score, every pricing change.

## Base URL

```text
https://api.llm-stats.com/stats/v1
```

## Authentication

Send your API key as a Bearer token on every request.

```bash
Authorization: Bearer YOUR_API_KEY
```

Request access and create keys from the [developer console](https://llm-stats.com/developer). See [Authentication](/api-reference/authentication) for key formats, organizations, and MCP sign-in.

## Endpoints at a glance

| Method | Path                       | Description                                                  |
| ------ | -------------------------- | ------------------------------------------------------------ |
| GET    | `/v1/models`               | Catalog with metadata, pricing, and category scores          |
| GET    | `/v1/models/{id}`          | Full model detail with every benchmark score                 |
| GET    | `/v1/benchmarks`           | All benchmarks with categories and model counts              |
| GET    | `/v1/scores`               | Score matrix — filter across models and benchmarks           |
| GET    | `/v1/rankings`             | TrueSkill rankings by category                               |
| GET    | `/v1/updates`              | Recently added models (1–30 day lookback)                    |

See the [Endpoints](/api-reference) section for full request and response schemas.

<Note>
  `/v1/updates` lists **recently added models** within a lookback window. It is
  not a change feed: it does not report score, ranking, or pricing changes, and
  it has no cursor. For durable creates, updates, and removals after a cursor,
  see the [incremental updates API](/api-reference/incremental-updates).
</Note>

Planned data routes:

## Discovering gateway-routable models

Every model returned by `/v1/models` and `/v1/models/{id}` carries an
`inference` block that tells you whether the model can be invoked
through the [LLM Stats gateway](/gateway/introduction) and the
canonical id to pass as `model`:

```json
{
  "id": "gpt-5-2025-08-07",
  "inference": {
    "available": true,
    "endpoint": "https://gateway.llm-stats.com/v1/chat/completions",
    "gateway_model_id": "gpt-5-2025-08-07",
    "openai_compatible": true,
    "supports_streaming": true,
    "supports_tools": true,
    "supports_vision": false,
    "docs_url": "https://docs.llm-stats.com/gateway/chat-completions"
  }
}
```

When `available` is `false`, the optional fields are omitted —
that model is in the catalog but cannot be called through the gateway.

## Errors, limits, and headers

- Every error uses one envelope with a stable `error.code`. See [Errors](/api-reference/errors).
- Burst limits and daily quotas apply per **organization**, not per API key. Creating another key does not create another quota pool. See [Rate limits and headers](/api-reference/rate-limits-and-headers).

## Attribution and rights

Community use is free within its limits and requires attribution when you show LLM Stats data publicly. Payment never grants redistribution rights: only a Commercial contract does. See [Attribution](/api-reference/attribution) and [Embeds and badges](/api-reference/embeds-and-badges).
